# StrataSignal development

This is the canonical product repository. The former portfolio directory is a migration pointer, not a second implementation.

Run Python checks with `python -m unittest discover -s tests -v` and the dependency-free path with `python -S -m unittest discover -s tests -v`. Report interaction checks use `npm ci --ignore-scripts` and `npm test`. Keep root-level packaging and workflows usable from a fresh checkout.

Use only fictional data in committed demonstrations. Keep private inputs/reports in ignored directories. Preserve strict input validation, local processing, exclusive output creation, inert JSON rendering and explicit synthetic/experimental labels. Describe implemented behavior and observed verification without inventing customer outcomes.

Keep technical specifications separate. Metadata inconsistencies are review signals. Scenario results are conditional calculations. ML estimates require the documented temporal evaluation and abstention gates. Update methodology and generated demonstration integrity manifests when behavior changes.
